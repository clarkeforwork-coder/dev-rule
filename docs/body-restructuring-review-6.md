## 固定格式與紀錄

- 指路句：`本組要求依〈來源連結〉、……辦理。`。實際集合範例見[作業說明](body-restructuring-guide.md)。group_routes 每筆列 heading、targets、text，來源須恰為該清空分組的已移除條文來源聯集。
- 結尾小節：獨立 `<a id="java-closing-requirements"></a>`，下接 `## 補充要求`；原尾段逐字保留，句子去向改到這個錨點。
- 引言補引用：`本文件另依〈來源連結〉、……辦理。`，link_retention 登錄；原共通連結的刪除例外須用 link_exceptions 逐筆附理由。
- 驗收第一欄：現行 Java 小節連結、共通連結，或純文字 `覆蓋要求（原驗收入口）`；以「、」分隔，不能附加政策。
- 固定保留清單：JN-05、JN-11、VO-09、ST-01、ST-07、CL-04、CL-07、EQ-02、EQ-03、EQ-05、EQ-06、EQ-07、EQ-09、EX-05、LS-04、LS-07、CA-03、BM-04、ND-02。由第四節 18 條扣 CA-06，再加 BM-04／ND-02 重算，工具同時核對清單與待決判斷。
