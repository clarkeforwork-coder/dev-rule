# ADR 0002：共通與語言規範分層

日期：2026-11-11

狀態：已決定

## 背景

PR #2 分離共通與 Java 規範，PR #3 補強語言增量與引用；重複維護相同要求容易造成更新不一致，本紀錄補記分層原則。

## 決策

每項要求只有一個主要維護位置，共同底線由共通主題檔維護，語言層只放語法、型別、標準 API 與執行模型等增量。引用具體規範要求的連結一律帶語意錨點，讓要求及驗收可直接追溯；文件索引等導覽連結不屬於要求引用。各層只能具體化或加嚴，不得自行降低共同底線；衝突須釐清修正，必要例外依既有核准流程處理。

## 後果

專案須合併閱讀適用的共通與語言要求，不能以語言文件未重述為由略過共同底線；搬移或刪除錨點時須同步修正引用並記錄對使用端的影響。
