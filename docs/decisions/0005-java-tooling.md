# ADR 0005：Java 自動檢查工具架構

日期：2026-11-11

狀態：已決定、實作中

## 背景

規範及文件檢查已建立，後續需要讓採用專案在開發與合併前取得一致的 Java 規範檢查；本紀錄保存已核准的工具方向，不代表工具已交付。

## 決策

Java 自動檢查工具放在 `tools/java/`，分為 IDE 即時回饋、pre-commit 提交前檢查、CI 合併門檻三層，使用一致的規則識別與判定依據。一條工具規則對應一個規範錨點，診斷可追溯到正式要求；規範的違反／符合範例作為工具測試資料，驗證應命中與不應命中的案例。

專案以明確 tag 固定引用的規範與工具版本，升級時檢視 CHANGELOG、評估規則變動並驗證後採用；不以浮動分支作為版本承諾。

## 後果

工具、規範及案例須同步維護，錨點變更會影響診斷與測試；三層檢查可提早提供回饋，仍不能取代無法自動判定的語意審查。`tools/java/` 的具體實作與首次版本 tag 留待後續交付。
