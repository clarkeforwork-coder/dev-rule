# ADR 0003：Java 支援版本與基線

日期：2026-11-11

狀態：已決定

## 背景

PR #8 補齊各版本的落實差異；若為每個版本複製規範，容易產生不同要求，本紀錄補記既有版本政策。

## 決策

支援 Java 8／11／17／21，主範例以 Java 17 為基線。版本差異內嵌於原要求小節，沿用該小節錨點，只描述實作方式，不得新增、放寬或免除要求；需要時提供對應版本範例。規範範例不得使用 Preview 功能。

新 JDK 發布不自動成為支援版本，須先盤點對各主題的影響、驗證工具鏈後才加入清單。移除支援版本須依[建置升級與支援範圍變更](../../rules/stacks/java/common/version-policy.md#java-build-upgrade)的既有流程決定，決定後從清單移除並清除該版本的條列與範例。

## 後果

舊版專案仍須達成相同要求，較新版本提供可選機制或加嚴；編譯基線與專案執行版本分別管理，不能以較新環境通過取代各承諾版本的執行驗證。

版本退場時，索引與檢查設定須同步更新；這是檢查器 V6 的索引一致性檢查與支援版本白名單設定所帶來的實作後果。
