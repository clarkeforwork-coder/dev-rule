# ADR 0001：儲存庫內容範圍

日期：2026-11-11

狀態：已決定

## 背景

規範庫以可供專案引用的規範為核心，需要避免過程文件與審閱報告混入正式內容；本紀錄補記既有內容邊界，並納入此次核准的治理檔案及後續 Java 工具位置。

## 決策

正式規範只放於 `rules/`；例外允許 `scripts/` 存放規範檢查、`.github/` 存放 CI 與審查設定、`docs/decisions/` 保存決策理由，以及 `tools/` 存放供專案使用的自動檢查工具。根目錄保留必要的儲存庫設定與版本紀錄，例如 `.gitignore`、`CHANGELOG.md`。過程文件、暫存資料與審閱報告不入庫，實際專案的配置及決策由各專案管理。

## 後果

引用者可辨識正式規範、治理紀錄及工具的用途；新增內容須落在明確範圍內，審查證據由 PR 或外部工作紀錄保存，不作為另一份規範來源。
