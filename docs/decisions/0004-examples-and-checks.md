# ADR 0004：範例與檢查

日期：2026-11-11

狀態：已決定

## 背景

PR #4 加入 Java 違反／符合範例，PR #5 建立統一檢查與 CI，PR #8 擴充版本檢查；本紀錄補記範例品質與合併門檻。

## 決策

Java 違反與符合範例都必須可編譯，違反範例用來呈現規範違反，不以語法錯誤代替。檢查器補上共用 import 後，以 `javac --release N` 驗證語法、型別與標準 API；未標版本的主範例使用 17，版本範例使用其標示的 8、11、17 或 21。

CI 固定使用 JDK 21，透過 `ruby scripts/check-rules.rb` 執行六項檢查：`links`、`skeleton`、`headings`、`template`、`examples`、`versions`；六項通過為合併門檻，失敗或略過不得視為通過，並保留獨立語意審閱。

## 後果

規範變更有可重現的機械驗證，維護者須具備相容的 Ruby 與 JDK 工具鏈；編譯不執行範例，無法證明執行期行為、要求完整性或範例語意正確，仍需人工審閱及適用的行為驗證。
