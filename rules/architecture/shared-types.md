# 共用型別管理

<a id="type-ownership"></a>
## 型別所有權與共用條件

- 模組公開的資料契約由提供方管理，使用方透過公開入口引用。
- 模組專屬型別保留在所屬模組，不因其他模組需要使用就移到全域共用區；對外提供資料仍須符合[邊界物件](boundary-objects.md#隔離與拆分)的隔離要求。
- 只有語意一致、穩定且確實需要共用的型別，才放入共用區，並明確指定維護責任。
- 共用型別不得反向依賴業務模組，不得形成循環依賴。
- 不得僅因欄位相同就合併型別，必須確認語意與變更需求一致。例如收件地址與帳單地址是否共用，不能只看目前欄位。

<a id="acceptance"></a>
## 驗收

驗收案例的選擇與維護依[驗收共同原則](../quality/testing.md#acceptance-principles)。

以依賴分析或架構檢查驗證循環依賴；以人工審查確認語意、所有權與共用必要性。例外依[規範治理](../workflow/rule-governance.md#例外核准)處理。
