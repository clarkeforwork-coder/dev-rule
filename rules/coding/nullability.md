# 空值語意

- 契約與型別必須明確表達業務需要區分的狀態，不得把未提供、明確清空與有值全部表示為同一個空值。
- 必填資料禁止空值；選填資料明確表達有值或無值。
- 部分更新若需要保留、移除與替換資料，必須表達以下三種意圖。

| 狀態 | 意圖 |
| --- | --- |
| 未提供 | 保留原值 |
| 明確清空 | 移除原值；該欄位必須允許清空 |
| 提供新值 | 依驗證結果更新 |

- 空字串、`0` 與空集合不自動視為缺值，是否允許及其意義由契約定義。
- 預設值必須有明確套用規則，不得用來掩蓋不合法輸入。
- 各語言如何表示上述狀態另行制定，不能只依賴反序列化後無法分辨來源意圖的空值。

行為測試應分別確認省略欄位、明確清空、提供新值與不合法值的結果。例外依[規範治理](../workflow/rule-governance.md)處理。
